# Tanamanies Cafe — Company Profile Kedai Kopi

Landing page company profile untuk kedai kopi fiktif di Bandung yang
dipenuhi tanaman.
Proyek ini adalah **concept demo** untuk portofolio jasa pembuatan web —
seluruh merek, konten, dan testimoni bersifat fiktif.

## Fitur

- Hero full-screen dengan CTA WhatsApp
- Marquee keunggulan, section Tentang dengan statistik
- Menu interaktif dengan tab kategori (Kopi / Non-Kopi / Pastry)
- Galeri foto dengan hover caption
- Testimoni pelanggan
- Info lokasi + jam buka + Google Maps embed
- Tombol WhatsApp mengambang
- Fully responsive & animasi scroll-reveal

## Tech Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion
- Lucide Icons

## Menjalankan

```bash
npm install
npm run dev      # development
npm run build    # production build ke folder dist/
npm run preview  # preview hasil build
```
